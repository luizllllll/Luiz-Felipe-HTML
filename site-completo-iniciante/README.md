# Meu Blog — projeto completo das aulas

Este projeto junta os conceitos dos três arquivos originais em um pequeno site.

## Como abrir

Abra o arquivo `index.html` com o Live Server.

## O que cada arquivo ensina

- `index.html`: estrutura semântica, títulos, textos, links e imagens.
- `cadastro.html`: formulário, `label`, `input`, `select`, `checkbox` e `button`.
- `flexbox.html`: relação entre elemento pai e elementos filhos.
- `style.css`: cores, espaços, classes, ID, Flexbox, efeito `hover` e responsividade.

## Correções feitas no código original

- O idioma mudou de `en` para `pt-BR`.
- O campo nome agora usa `type="text"` e possui o `id` correto.
- O texto do plano deixou de ser “E-mail”.
- A tag escrita como `lqbel` foi corrigida para `label`.
- Todas as páginas agora têm `<!DOCTYPE html>` e títulos claros.
- Os links do menu agora levam para páginas ou seções existentes.
